GET UP AND RUNNING

A little setup.
A lot of button.

Use the CDN for a quick start, or install Bootstrap with npm in your project. This demo’s interactions live in a separate JavaScript file.

✳Choose one Bootstrap install method for your own app: CDN or npm.
QUICK START 3 simple steps
01# Install with npm
02npm install
03<!-- Or add Bootstrap via CDN -->
04<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
05<!-- Bootstrap bundle + your external script -->
06<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
07<script src="./app.js" defer></script>
08# Start the demo app
09npm run dev
Ready when you are.
